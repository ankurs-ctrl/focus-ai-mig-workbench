Important caveat:
this table is still only partially compatible unless this is also true:
USER_ID must already contain a numeric or numeric-string app id
each user should already have a row in TBL_USERS
Why: the current code does:
lookup by OKTA_SUB
update LAST_SEEN_DATETIME
later casts USER_ID using int(row["USER_ID"])
So if:
OKTA_SUB is missing -> current error
but after that, if USER_ID is not numeric, the next error will come
So the safe client fix is:
Add OKTA_SUB
Add LAST_SEEN_DATETIME
Fill OKTA_SUB for every real user
Make sure USER_ID values are numeric-like for those rows
