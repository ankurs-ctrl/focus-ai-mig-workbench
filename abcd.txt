### 1. High: a late proposal can overwrite a newer saved edit

**Reproduction:** start Auto-map → edit and save an imported expression → receive the old run’s proposal → click Accept or Accept all.

The proposal receives the **edited row’s current revision**, making the stale proposal appear valid. Acceptance then overwrites the saved edit.

**Fix:** compare against the row revision captured when the run started, including preserved-baseline proposals. Never stamp a stale proposal with the current row revision.

Location: `frontend/src/features/sttm/store/sttm-builder-slice.ts:2700–2706`

### 2. An unresolved reevaluation can erase an existing mapping

Unresolved reevaluations bypass the executable-proposal check and are accepted as replacements.

Reproduced through both acceptance actions for:
- Existing source mappings.
- Empty-string constants.
- Project-attribute mappings.

Acceptance cleared the existing definition and left the row unmapped.

**Fix:** unresolved outcomes must remain informational/review items, not applicable replacements. Preserve the existing definition.

Locations: `sttm-builder-slice.ts:2633–2646` and `:5165–5195`

### 3. Invalid block-review responses are accepted

The evidence-block validator accepts otherwise valid responses containing either:
- Nested `data.meta.delegation`.
- A conflicting top-level `result.mappings`.

Durable-runtime probes showed these responses marking evidence as reviewed and allowing the subsequent proposal. **No delegation executed or foreign mapping was applied**, and the proposal remained review-only—but the evidence-review gate was incorrectly satisfied.

**Fix:** validate the entire response envelope, including nested metadata and conflicting result locations.

Location: `services/sttm-builder/app/core/automap_evidence_blocks.py:193–213`

### 4. Failed continuation loses verified alternatives

A target initially retained a verified alternative and explanation. After subsequent invalid proposals, the terminal result replaced them with:

```text
candidate_source_attributes: []
confidence_reason: null
```

The valid sibling survived, but the unresolved target lost useful evidence.

**Fix:** preserve previously verified alternatives and explanations when later repair/retrieval fails. Do not retain fabricated alternatives.

Locations: `services/sttm-builder/app/core/automap_batch.py:903–906` and `:1035`
