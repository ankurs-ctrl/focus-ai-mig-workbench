Hi team, two separate issues need attention:

**1. Session redirect loop**

Middleware checks whether the session cookie **exists**, while SessionGate checks whether it is **valid**. When the session is rejected, the cookie remains:

```text
/dashboard → Session rejected → /home
     ↑                             |
     └─ Middleware sees old cookie ┘
```

This keeps repeating “Checking your session / Redirecting to sign in.” Incognito works with a fresh login.

**Fix:** Clear the invalid session cookie through the backend before redirecting, keep sign-in reachable, and handle permission errors separately.

**2. Dashboard/Projects caching**

Current behavior:
```text
Open page → Cached data → Fast
After 5 minutes → Cache expires → Blocking fetch → Wait
```

Recommended:
```text
Open page → Show cached data immediately
                    ↓
          Refresh in the background if stale

Autosave → Check what changed
           ├─ Mapping-only state → Keep summaries unchanged
           └─ Summary fields → Update affected entries only
```

Keep caches scoped to user/role and clear them on logout or identity changes. Fix mapping-detail expiry to use `Date.now() + TTL`.

These fixes are not implemented yet.
