he USERNAME and PASSWORD in the Snowflake secret are not a human username/password.
They should be the OAuth client credentials generated by the security integration.
After creating the OAuth integration, please run:
DESC SECURITY INTEGRATION <OAUTH_INTEGRATION_NAME>;

SELECT SYSTEM$SHOW_OAUTH_CLIENT_SECRETS('<OAUTH_INTEGRATION_NAME>');
That returns the OAuth client details.
Then create the secret like this:
CREATE OR REPLACE SECRET <APP_DB>.<APP_SCHEMA>.STTM_BUILDER_OAUTH_CLIENT_CREDENTIALS
  TYPE = PASSWORD
  USERNAME = '<OAUTH_CLIENT_ID_FROM_SYSTEM_SHOW>'
  PASSWORD = '<OAUTH_CLIENT_SECRET_FROM_SYSTEM_SHOW>';
