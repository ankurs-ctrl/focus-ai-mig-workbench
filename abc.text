No data needs to be deleted. Run this one-time reconciliation, then rerun bootstrap.
1. Drop Legacy FIR Constraints
From the repository root:
$Snow = ".\.client-tools-venv\Scripts\snow.exe"
$Connection = "<SNOWFLAKE_CONNECTION from client.env>"

$FixSql = @'
EXECUTE IMMEDIATE
$$
DECLARE
    drop_sql STRING;
    legacy_checks CURSOR FOR
        SELECT tc.CONSTRAINT_NAME
        FROM FFP_HDP_DLAB_DB_DEV.INFORMATION_SCHEMA.TABLE_CONSTRAINTS tc
        INNER JOIN FFP_HDP_DLAB_DB_DEV.INFORMATION_SCHEMA.CHECK_CONSTRAINTS cc
            ON cc.CONSTRAINT_CATALOG = tc.CONSTRAINT_CATALOG
           AND cc.CONSTRAINT_SCHEMA = tc.CONSTRAINT_SCHEMA
           AND cc.CONSTRAINT_NAME = tc.CONSTRAINT_NAME
        WHERE UPPER(tc.TABLE_SCHEMA) = 'SCH_STTM_METADATA'
          AND UPPER(tc.TABLE_NAME) = 'TBL_FIR_AGENT_RECOMMENDATIONS'
          AND UPPER(tc.CONSTRAINT_TYPE) = 'CHECK'
          AND (
              UPPER(cc.CHECK_CLAUSE) LIKE '%TRIGGER_TYPE%'
              OR UPPER(cc.CHECK_CLAUSE) LIKE '%RECOMMENDATION_TYPE%'
          );
BEGIN
    FOR constraint_row IN legacy_checks DO
        drop_sql :=
            'ALTER TABLE FFP_HDP_DLAB_DB_DEV.SCH_STTM_METADATA.' ||
            'TBL_FIR_AGENT_RECOMMENDATIONS DROP CONSTRAINT "' ||
            REPLACE(constraint_row.CONSTRAINT_NAME, '"', '""') || '"';

        EXECUTE IMMEDIATE :drop_sql;
    END FOR;
END;
$$;
'@

& $Snow sql -c $Connection -q $FixSql
This removes only the obsolete TRIGGER_TYPE and RECOMMENDATION_TYPE checks. It preserves the table and every existing recommendation.
2. Confirm Constraints Were Removed

WHERE UPPER(tc.TABLE_SCHEMA) = 'SCH_STTM_METADATA'
  AND UPPER(tc.TABLE_NAME) = 'TBL_FIR_AGENT_RECOMMENDATIONS';
