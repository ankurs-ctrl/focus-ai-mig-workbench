3. OUR AUTO-MAP CHANGES — CUMULATIVE BEHAVIOR

- No checked rows: request fresh proposals for all targets, including already-mapped rows. Checked rows: request exactly that set.
- Supported replacements apply to requested rows; previous definitions remain available for Undo. Edits made during a running job retain per-row protection. Identical supported proposals count as unchanged reevaluations.
- Reuse selection-page prepared semantic/FIR evidence. Cached/cold and restored workspaces complete the server-owned execution context/frozen handoff; background counts/recommendations/unchanged Values do not masquerade as authored edits.
- Read pipeline-published semantic assets. Missing/all-missing YAML is a coverage gap, not an automatic refusal when current bindings/history support a result. Do not regenerate semantic assets for this release.
- Frozen, target-specific source packets retain authorization, revision, generation, hashes, exact identities and evidence coverage. Workers verify the dispatch packet instead of freely reconstructing a different message.
- Final source/transformation messages are budgeted against both the existing 180,000-character and UTF-8-byte limits. Optional evidence is deferred atomically; complete expressions/CTEs are not cut. Oversized groups can subdivide without discarding fitting siblings.
- Citation IDs such as src:ACCOUNTS.ADDRESS1_COUNTRY resolve only to uniquely authorized selected outputs, including required_columns/dependencies and CTE boundaries. Ambiguous references are not guessed.
- Direct columns/constants/direct approved Values skip the transformation specialist. Custom SQL/NL intent, CASE, concatenation, conversions and column-plus-Value or Value-only expressions route through the specialist even when the source label was incorrectly Direct/unresolved.
- Specialists receive original requirements, current bindings/Values and relevant frozen historical expressions. Missing CTE/join/business Values retain supported intent plus evidence-backed dependency information; historical firm literals are not silently substituted.
- Backend estimated confidence is deterministic; numeric model confidence remains separately attributable. Scores, selected candidates and custom rules survive persistence/reopen.
- Working/copied/compiled SQL uses readable collision-safe aliases. Internal source identities still exist for correctness; they are not intended as business-facing alias labels.
- Readable model-authored suggestions remain separate from compiler/transport/packing diagnostics. Useful supported low-confidence results are not withheld for a new business approval gate. Publishing stays separate.
- Stable current-generation target totals and application counts distinguish newly applied, replaced, unchanged, held for edits and unsupported outcomes. Specialist counts do not replace overall totals.
- Ownership-only Auto-map dispatch retains fencing/recovery without the old shared application slot ceiling. Parallel scheduling is still bounded by the existing worker/provider configuration; it is not unlimited concurrency.
- Independent worker sessions, combined thread/request handoff, terminal-receipt reuse and reduced redundant persistence reduce execution overhead. Safe native diagnostics and phase timings survive failures. Uncertain calls/commits are reconciled, never blindly replayed.
