What to check next, exactly
In your rendered service spec, verify the value:
confirm APP_ROLE_ADMIN: FFP_HDP_DLAB_DB_DEPLOY_ROLE_DEV

In backend logs or /api/v1/auth/snowflake-context, verify:
CURRENT_ROLE()
whether the app thinks you are ADMIN

Most important Snowflake-side check:
run this as the same logged-in user/session path if possible:
SELECT
  CURRENT_USER(),
  CURRENT_ROLE(),
  IS_ROLE_IN_SESSION('FFP_HDP_DLAB_DB_DEPLOY_ROLE_DEV');

If that last value is FALSE, then we found the real reason.
