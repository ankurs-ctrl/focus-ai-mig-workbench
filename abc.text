```powershell
$snowflakeUserSessionCacheTtl = if (
```

Add these exports before rendering the service specifications:

```powershell
$env:SNOWFLAKE_SEMANTIC_NATIVE_VIEWS_TABLE = if (
    $cfg.ContainsKey("SNOWFLAKE_SEMANTIC_NATIVE_VIEWS_TABLE") -and
    $cfg["SNOWFLAKE_SEMANTIC_NATIVE_VIEWS_TABLE"]
) {
    $cfg["SNOWFLAKE_SEMANTIC_NATIVE_VIEWS_TABLE"]

    "LATEST_NATIVE_VIEWS"
}

$env:SNOWFLAKE_USER_SESSION_CACHE_TTL_SECONDS = $snowflakeUserSessionCacheTtl
```

Also change the fallback values in the safe script to:

```powershell
else { "LATEST_TABLE_VIEWS" }
else { "LATEST_COLUMN_VIEWS" }
```

instead of local metadata `SEM_TABLE_VIEWS` and `SEM_COLUMN_VIEWS`.
