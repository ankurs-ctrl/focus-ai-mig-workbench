docker build --platform linux/amd64 -t "$REGISTRY_BASE/sttm-builder:$IMAGE_TAG" .\services\sttm-builder
docker push "$REGISTRY_BASE/sttm-builder:$IMAGE_TAG"
7. Build and push frontend image

docker build --platform linux/amd64 -t "$REGISTRY_BASE/frontend:$IMAGE_TAG" .\frontend
docker push "$REGISTRY_BASE/frontend:$IMAGE_TAG"
8. Build and push nginx image

docker build --platform linux/amd64 -t "$REGISTRY_BASE/nginx:$IMAGE_TAG" .\nginx
docker push "$REGISTRY_BASE/nginx:$IMAGE_TAG"

Fix the bad $EnvFile: interpolation
Change this block:

if ($missing.Count -gt 0) {
    Fail "Missing required local Snowflake settings in $EnvFile: $($missing -join ', ')"
}
to:

if ($missing.Count -gt 0) {
    Fail ("Missing required local Snowflake settings in {0}: {1}" -f $EnvFile, ($missing -join ', '))
}
That removes the :$ parsing problem.

3. Remove ?? because Windows PowerShell doesn’t support it
Change this:

$enabled = ($envValues["LOCAL_DEV_AUTH_ENABLED"] ?? "").ToLowerInvariant()
to:

$enabled = ""
if ($envValues.ContainsKey("LOCAL_DEV_AUTH_ENABLED") -and $null -ne $envValues["LOCAL_DEV_AUTH_ENABLED"]) {
    $enabled = [string]$envValues["LOCAL_DEV_AUTH_ENABLED"]
}
$enabled = $enabled.ToLowerInvariant()
And change this:

$authenticator = ($envValues["SNOWFLAKE_AUTHENTICATOR"] ?? "").ToLowerInvariant()
to:

$authenticator = ""
if ($envValues.ContainsKey("SNOWFLAKE_AUTHENTICATOR") -and $null -ne $envValues["SNOWFLAKE_AUTHENTICATOR"]) {
    $authenticator = [string]$envValues["SNOWFLAKE_AUTHENTICATOR"]
}
$authenticator = $authenticator.ToLowerInvariant()
