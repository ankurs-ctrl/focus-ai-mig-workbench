## Update your safe script

In `deploy_spcs_client_snow_safe.ps1`, replace your `Build-AndPushImage` function with this:

```powershell
function Build-AndPushImage {
    param(
        [string]$Name,
        [string]$ContextDir,
        [string]$RemoteImage,
        [string[]]$BuildArgs = @()
    )

    $dockerArgs = @(
        "build",
        "--platform", "linux/amd64"
    )

    foreach ($arg in $BuildArgs) {
        $dockerArgs += "--build-arg"
        $dockerArgs += $arg
    }

    $dockerArgs += "-t"
    $dockerArgs += $RemoteImage
    $dockerArgs += $ContextDir

    Invoke-Checked -Description "Building Docker image $Name -> $RemoteImage" -Command {
        docker @dockerArgs
    }

    Invoke-Checked -Description "Pushing Docker image $RemoteImage" -Command {
        docker push $RemoteImage
    }
}
```
